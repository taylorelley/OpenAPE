# Review of OpenAPE 0.1.0 against the brief, and 0.2.0 fixes

Reviewed 2026-10-22 against `docs/original-brief.md`. Severity is relative to the
brief's intent ("a real learnable personality with honest tests and a stable
public adapter protocol").

## Defects found and fixed

| # | Finding (0.1.0) | Brief | Fix (0.2.0) | Evidence |
|---|---|---|---|---|
| 1 | **Decoder ignored persona state.** Trained with random latent noise and latent-independent labels, so every neutral persona chose identical controls; "learning" could only move a latent the decoder barely used. | §3.3, §13.2 | Auto-decoder training on 544 synthetic persona profiles (persona-partitioned); latents genuinely condition behaviour. | Held-out personas fitted from 16 pairs: top-1 0.66 vs 0.12 neutral (`decoder.json`); `tests/test_learning.py` |
| 2 | Seed preferences recorded but never applied. | §4.2 | Deterministic seed-latent fitting, labelled `seed_preferences`; conflicts rejected. | Two seeded personas pick different controls in identical contexts (unit + Claude Code smoke) |
| 3 | Trainer computed its own held-out metrics and called the evaluator. | §3.5 | `engine/evaluation` owns split, re-scoring and thresholds; trainer only fits. | ADR 0002 |
| 4 | Revoking any core evidence reset the persona to its root and **deleted all versions**, even for unused evidence. | §3.4, §8 | Lineage-based revocation: only derived candidates/versions (and descendants) are revoked; active moves to the nearest clean ancestor. | `test_revocation_follows_lineage_only` |
| 5 | **Hermes plugin could never inject**: it called `ctx.get_config`, which Hermes 0.19 does not provide. | §7.2 | Profile-scoped `get_secret`; stdlib-only; subagent opt-out. | Real Hermes 0.19.0 smoke 13/13 |
| 6 | **OpenClaw plugin never injected** on the embedded runner (required `currentUserMessageId`, which that runner omits) and lacked activation metadata, so it never loaded. | §7.5 | Admission id or run id; explicit empty request/heartbeat/cron opt out; `activation.onStartup`; `plugins.allow` documented. | Real OpenClaw 2026.10.5 smoke 9/9 |
| 7 | Claude Code adapter was a single UserPromptSubmit settings snippet; no plugin, no lifecycle hooks, required the full engine environment in the hook interpreter. | §7.3 | Installable plugin + marketplace; SessionStart/Stop/StopFailure/PostCompact/PostModelSwitch/SessionEnd; stdlib-only hook; once-per-prompt guard; subagent opt-out. | Real Claude Code 2.1.307 smoke 10/10 |
| 8 | OpenCogni: service stub with no planner effect. | §7.4 | `presentationStyle` boundary on `planner.http` as a separately reviewable upstream patch (+3 contract tests); `brain.personality` provider logs decision/version/decoder hash. | Patched planner smoke 4/4; OpenCogni unit suite 74 passed |
| 9 | Hashed context features collided; 20-row catalogue lacked low directness, assertiveness variation and high humour. | §3.1–3.2 | encoder/2 one-hot slots; 24-row audited catalogue; `urgent` mask. | `protocol/catalogue.py` |
| 10 | REINFORCE used a fixed zero baseline; duplicate judgements under new feedback IDs trained repeatedly. | §3.4, §4.5 | Mean-reward baseline; one example per (decision, actor, kind). | `test_duplicate_judgement_under_new_id_counts_once` |
| 11 | KL drift budget (0.15 nats) was meaningless for a sharp decoder and blocked real learning. | §3.4 | Latent trust region (core 1.0, relationship 1.5) and absolute norm bound; KL reported. | ADR 0002 |
| 12 | Python SDK imported engine contracts (pydantic); TS/Python renderers had no shared golden text. | §2, §4 | `sdk/python/lite.py` stdlib renderer/client vendored byte-identically into plugins; golden `rendered` fixtures in both SDK suites. | `tests/test_conformance.py`, `sdk/typescript/test.ts` |
| 13 | Missing operations: restricted host tokens, preview, adapter install/doctor, SOUL migration, subagent snapshots, frozen version pinning, feedback timestamps. | §5, §6, §7.2, §11 WP7 | `openape token add`, `preview`, `job`, `adapter install/uninstall/doctor/migrate-soul`; `parent_persona_id`; `pinned_version`; `occurred_at`/`evidence_refs`. | `tests/test_cli.py`, Hermes smoke |
| 14 | No A/B/C/D run of any kind. | §10 | Simulated-user benchmark through the real API with paired clustered CIs, clearly labelled non-human. | `benchmarks/reports/simulated.json` |

## Deliberate deviations from the brief

* **KL budget → latent trust region** (finding 11), to make slow, bounded learning
  possible while still enforcing an explicit drift budget.
* **Session vector stays zero** (optional in §3.1); not worth the complexity without
  evidence.
* **OpenCogni planner change is not pushed upstream** from this session; it ships as a
  patch for separate review, as §0 requires.
* **SOUL migration edits SOUL.md only with `--apply`** after an exclusive backup;
  coexistence is the default because Hermes 0.19 cannot omit SOUL.md alone.

## Still open (not claimed)

Live provider models across three families, independent human A/B/C/D evidence,
OpenCogni upstream merge and integration suites, OS-isolated evaluator, Docker
re-verification for 0.2.0, security/licence audits. See `open-issues.md`.
